# Original work and references

This independent portfolio project was developed for Vedant Thaker with AI implementation assistance. Its report structure follows Vedant's supplied examples: define the decision, inspect the evidence, test the failure boundary, measure the result, and state the limit. The private source prompts and resume are not included.

The implementation and fictional fixtures are original. No historical employer performance, client use, or business result is established by this repository.

Conceptual reference: [ECC](https://github.com/affaan-m/ECC), MIT, inspected at commit `b38be6a7f6350964d59328b52f0624e1d1d552d1`.

- [Unified memory](https://github.com/affaan-m/ECC/blob/b38be6a7f6350964d59328b52f0624e1d1d552d1/skills/unified-memory/SKILL.md): inspectable handoff records, scope boundaries, and recalled context as evidence rather than authority.
- [Context and decisions](https://github.com/affaan-m/ECC/blob/b38be6a7f6350964d59328b52f0624e1d1d552d1/skills/context-and-decisions/SKILL.md): durable context and explicit decision records.
- [Evaluation harness](https://github.com/affaan-m/ECC/blob/b38be6a7f6350964d59328b52f0624e1d1d552d1/skills/eval-harness/SKILL.md): define observable acceptance criteria before assessing a workflow.

ECC code, installers, and memory runtime were not copied or executed. This project uses its own JSON schema, revision resolver, byte-budget packer, and authored contract comparison. The recent-first baseline and validity-aware recency ablation were written here; neither is a benchmark of ECC's memory implementation.
